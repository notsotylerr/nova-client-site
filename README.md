# Nova Client

Website for **Nova Client**, a Minecraft: Java Edition client by NotSoTylerr.

Live site: https://getnovaclient.com

## What's on the site

- **Registration info**: details of Nova's Microsoft app registration (app name, client ID, redirect URI and the data it uses), for transparency.
- **FAQ**: how sign-in works, what you need to own, how to remove Nova's access, multiple accounts and performance.

## Privacy

Nova signs you in through Microsoft's official login page and never sees your password. Login tokens stay on your own computer. The only data used is your Minecraft profile (username, UUID, skin).

## Hosting

Static site served with GitHub Pages. `index.html` is the page and `CNAME` sets the custom domain.
