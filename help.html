Need a hand?

Check the common fixes below first. If that doesn't sort it, report it and NotSoTylerr will take a look.

🐞Report a bugSomething isn't working 💡Suggest an ideaSomething you'd like NOVA to do 🔎Known issuesSee if it's already reported

Reports are posted on GitHub, so you'll need a free GitHub account. Everything posted there is public: never include passwords or codes.

The best way to report a bug

  1. In NOVA, click ••• (top right) → Report a problem.
  2. Read it through, then click Copy report. Private details like passwords, tokens, IP addresses and your username are removed automatically.
  3. Click Report a bug above, say what you were doing, and paste the report in.

Common fixes

Signing in says “Invalid app registration” (HTTP 403)

NOVA is still waiting for Mojang to approve it for Minecraft sign-in. Your Microsoft account is fine. It will start working for everyone automatically once it's approved, with no reinstall needed.

Windows says “Windows protected your PC”

That's Microsoft SmartScreen. It shows for new apps that aren't code-signed yet. Click More info, check the file is NOVA-Setup.exe, then Run anyway. You only see it once: NOVA updates itself after that.

How do I update NOVA?

You don't need to. NOVA checks for updates when it opens and every few hours, and installs them when you're not playing. Your version is shown in the bottom-right corner. To check straight away: ••• → Updates → Check now.

A new update broke something

Go to ••• → Updates → Go back to return to the previous version. NOVA skips the broken one until a fix is released. Please report the bug so it gets fixed.

“NOVA is already running”

Another NOVA window is open, possibly minimized or in the system tray near the clock. Close it, or end NOVA in Task Manager (Ctrl + Shift + Esc).

The game crashes or won't start

Open the setup in Versions and try Repair install. If you added mods, check for a mod updates button, or remove the newest mod. Still stuck? Report a bug with the problem report: it includes the crash details.

Where are my worlds and settings?

In %LOCALAPPDATA%\NOVA. Each setup has its own folder. Use Open folder on a setup's page. Updates never delete them.
